# Genetic Counselling Support System (GCSS)

GCSS is a web-based Database Management System designed to support genetic counsellors in assessing and managing the risk of inherited genetic disorders. It combines genetic data, patient records, and family history to provide personalized, data-driven risk assessments.

## Project Overview

Genetic counselling helps individuals and families understand genetic conditions and their risks. With increasing availability of genetic testing, GCSS aims to streamline this process using a secure and intelligent system that:

- Stores patient data, genetic test results, and family history  
- Analyzes inherited genetic patterns using custom algorithms  
- Generates detailed risk assessments and reports for counsellors

## Key Features

- Secure Database – Stores genetic data, patient information, and family history  
- Risk Assessment Engine – Analyzes genetic data to predict inherited disorder risks  
- Report Generation – Creates detailed and visual reports for counselling sessions  
- Integration Ready – Compatible with external genetic testing services  
- Compliance-Focused – Maintains data privacy and regulatory standards  

## System Architecture

- Frontend: Web interface for data input and viewing results  
- Backend: Algorithms for risk assessment and decision support  
- Database: Secure storage for genetic, medical, and family history data  
- Reporting Module: Generates personalized counselling reports  

## Tech Stack

- Frontend: HTML/CSS/JavaScript or React  
- Backend: Python (Flask/Django) or Node.js  
- Database: MySQL / PostgreSQL  
- Security: Authentication, role-based access, data encryption  

## How to Use

1. Register/Login as a genetic counsellor  
2. Add Patient Information, including family history and genetic test results  
3. Run Risk Assessment to analyze the likelihood of inherited disorders  
4. Download Reports for patient consultations  

## Out of Scope

- Non-genetic medical conditions  
- Diseases not inherited genetically  

## Outcomes

- Faster, more accurate risk assessments  
- Enhanced patient care with data-backed insights  
- Streamlined workflow for counsellors
